Smart Rail Explorer is a comprehensive train booking and management web application built using the MERN stack and Firebase. This platform allows users to search for direct and connecting train routes, select preferred travel classes (AC, Sleeper, General) with dynamic pricing, and perform real-time seat booking.
✨ Key Features
Intelligent Search: Algorithm-based search for direct and split (connecting) train routes.
Dynamic Pricing: Class-based pricing integration (AC, Sleeper, General) with real-time updates.
Secure Authentication: Firebase-powered user sign-up and login system.
Booking Management: Real-time seat availability tracking and cancellation functionality.
Digital Ticket Generation: Professional booking confirmation with dynamic PNR generation and print-ready ticket UI.
Responsive UI: Clean and professional interface for a seamless user experience.
🛠 Tech Stack
Frontend: React.js, Axios, CSS3
Backend: Node.js, Express.js
Database: Google Firestore (Firebase)
Authentication: Firebase Auth
